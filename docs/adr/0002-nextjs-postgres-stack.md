# Next.js and Postgres stack

The app is a single Next.js (App Router) TypeScript codebase on Postgres, using Drizzle for data access and Better Auth with roles enforced on the server. It's deployed with Docker Compose on a VPS. PDFs (Report Cards, Payment Records) are rendered from HTML with Playwright, and email is sent over SMTP through a provider that can be swapped out. One full-stack framework and one relational database suit a single-school deployment, and grades, enrollments and fees are relational data that needs integrity. Node with EJS and Prisma were the alternatives considered. v1 is a responsive web app with no native client.
