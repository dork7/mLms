# 05: Student registration and login

**What to build:** The Admin registers Students by hand, assigning each a Student Number that becomes their login. Students log in with their Student Number and password.

**Blocked by:** 02 (Staff accounts)

**Status:** resolved

- [x] The Admin registers a Student with their name, date of birth, national ID, guardian contact, optional single email, photo, admission date and Student Number
- [x] A duplicate Student Number is refused
- [x] A Student logs in with their Student Number and password, and must change the password on first login
- [x] The Admin can reset a Student's password and disable their login
- [x] A Student can see only their own profile
