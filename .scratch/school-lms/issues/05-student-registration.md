# 05: Student registration and login

**What to build:** The Admin registers Students by hand, assigning each a Student Number that becomes their login. Students log in with their Student Number and password.

**Blocked by:** 02 (Staff accounts)

**Status:** ready-for-agent

- [ ] The Admin registers a Student with their name, date of birth, national ID, guardian contact, optional single email, photo, admission date and Student Number
- [ ] A duplicate Student Number is refused
- [ ] A Student logs in with their Student Number and password, and must change the password on first login
- [ ] The Admin can reset a Student's password and disable their login
- [ ] A Student can see only their own profile
